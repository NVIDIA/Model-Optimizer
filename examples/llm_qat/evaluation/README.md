# Evaluation

NeMo Evaluator Launcher (NEL) configurations and evaluation artifacts for the [Hugging Face QAT/QAD tutorial](../README.md).

- `nel_configs/`: shared benchmark recipes.
- `results/<model-and-hardware>/<benchmark-and-scope>/`: each evaluation's `nel_config.yaml` and original `lm_eval_results_*.json` generated by lm-evaluation-harness. Per-example samples are not stored here.

## Results

Qwen3-8B was evaluated using NEL with vLLM on one H100 per evaluation. QAD starts from the PTQ checkpoint and uses the BF16 model as teacher.

| Checkpoint | Deployed precision | MMLU accuracy ↑ | WikiText-2 perplexity ↓ |
|---|---|---:|---:|
| Teacher (BF16) | BF16 | [74.94%](results/qwen3-8b_h100_teacher_bf16/mmlu_full/lm_eval_results_2026-10-08T09-24-34.263592.json) | [13.485](results/qwen3-8b_h100_teacher_bf16/wikitext_full/lm_eval_results_2026-10-08T07-22-39.797863.json) |
| PTQ (NVFP4) | NVFP4 weights / BF16 activations | [73.59%](results/qwen3-8b_h100_ptq_nvfp4/mmlu_full/lm_eval_results_2026-10-08T10-29-11.704256.json) | [13.883](results/qwen3-8b_h100_ptq_nvfp4/wikitext_full/lm_eval_results_2026-10-08T07-23-16.887993.json) |
| PTQ → QAD (NVFP4) | NVFP4 weights / BF16 activations | [73.76%](results/qwen3-8b_h100_ptq_then_qad_nvfp4/mmlu_full/lm_eval_results_2026-10-08T11-35-03.360012.json) | [13.684](results/qwen3-8b_h100_ptq_then_qad_nvfp4/wikitext_full/lm_eval_results_2026-10-08T07-23-24.097523.json) |

QAD improves both metrics over PTQ but remains below the BF16 teacher. The quantized checkpoints use Marlin's W4A16 fallback on H100; these results do not measure native NVFP4 W4A4 execution on Blackwell. KV cache is BF16 for all checkpoints.
