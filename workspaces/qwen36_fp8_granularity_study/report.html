Mathematical lens

For E4M3, ModelOpt maps values into a finite FP8 grid after scaling. These candidates vary which values share a scale, when the scale is obtained, and whether it is full precision or the E8M0 power-of-two scale used by MXFP8. The primary W8A8 result is therefore a comparison of complete numerical-format policies, not a causal estimate of granularity alone.

Q(x) = s · FP8_E4M3(clamp(x / s, −448, 448))Per-tensor FP8 uses one calibrated s; block formats recompute or store local scales.
s_MX = 2^ceil(log₂(amax / 448))MXFP8's E8M0 scale protects the local block from clipping, but power-of-two rounding can leave up to roughly 2× range slack.
NMSE_Qwen = meanₜ [ meanᵥ((q̃ₜ − r̃ₜ)²) / (meanᵥ(r̃ₜ²) + ε) ]q̃ and r̃ are centered over vocabulary for each scored token. The report averages tokenwise ratios, so each valid next-token position has equal weight.
KL(Pᵣ || Pq) = Σᵥ Pᵣ(v) · [log Pᵣ(v) − log Pq(v)]Forward KL measures reference probability mass lost by quantization; reverse KL and Jensen–Shannon expose different tail behavior.

Hypotheses to test, not results

  • A sufficiently extreme outlier can inflate a per-tensor scale enough to coarsen or underflow ordinary values that share it.
  • 128-value/128×128 local scaling should isolate outliers, with modest scale overhead.
  • MXFP8's 32-value blocks offer stronger isolation, while E8M0 scale rounding can reduce effective mantissa use compared with a full-precision local scale.
  • Output KL need not track weight MSE monotonically: errors in sensitive projections and router-adjacent paths can matter more than aggregate squared error.

Measurement protocol

Pin inputs
Resolve model revision, tokenizer, dataset sample IDs, padding, sequence length, dtype, and random seeds.
Cache reference
Persist BF16 logits and a matching manifest before any in-place quantization.
Apply one candidate
Use ModelOpt fake QDQ; refresh research block-reshape state per invocation for variable routed-MoE shapes.
Measure globally
Mask padding; compute MSE, normalized MSE, bidirectional KL, JS, target log-p, ΔNLL, top-k agreement, and document bootstrap intervals.
Localize error
Measure all weight/expert slices directly, hook input quantizers, and retain family summaries, provenance, coverage, and wall times.
Fixed deterministic screen: 128 packed calibration samples and 32 evaluation documents from row offset 1024 of the same CNN/DailyMail training split; batch 1; padded sequence length 512. The 32-document evaluation slice is a controlled numerical screen, not evidence of broad task or corpus generalization. Outer batch and padded sequence shapes are matched for control; a research-only pre-hook refreshes block reshape caches per invocation for variable fused-MoE routed-token shapes.

Interpretation guardrails

  • Treat the W8A8 matrix as a format-level comparison, not a causal granularity ablation: per-tensor activations use a static calibrated scale, block-128 and MXFP8 activations use dynamic per-invocation scaling, and MXFP8 additionally changes block size and scale encoding.
  • The W8A16 controls isolate activation-quantization scope, but they do not isolate every format choice: MXFP8 versus block-128 still combines 32-value versus 128/128x128 scale domains with E8M0 versus full-precision scale representation.
  • The 32 CNN/DailyMail evaluation documents form a deterministic same-split numerical screen; do not generalize their ordering to downstream tasks, other corpora, or full model quality.
  • Qwen normalized MSE is a mean of per-token ratios. The synthetic toy uses one ratio of global element means, so the two normalized-MSE values are conceptually related but not numerically interchangeable.
  • The dynamic block-128 candidate is a numerical simulation using full-precision dynamic scales, not evidence of an exportable or accelerated runtime format.
  • Raw vocabulary-logit MSE depends on logit offset and scale; centered/variance-normalized MSE and distribution divergences are the cross-model anchors.
  • AutoQuant KL is useful for candidate ranking but is a raw summed internal score; it is not substituted for token-normalized end-to-end KL.
  • No Qwen3.6 number appears in the report unless it was parsed from a result artifact.
