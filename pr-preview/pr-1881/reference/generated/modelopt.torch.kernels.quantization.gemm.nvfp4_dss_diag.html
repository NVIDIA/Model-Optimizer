nvfp4_dss_diag

Diagnostic Triton kernel for Decoupled Scale Search (DSS) on the NVFP4 weight-MSE sweep.

DSS (SOAR, arXiv:2605.12245) decouples the FP4 quantization scale s_q (high precision) from the stored dequantization scale s_d (FP8 E4M3-constrained):

for s_d in nearby_E4M3_scales:  # stored, FP8-constrained
    for s_q in nearby_real_scales:  # free, high-precision
        q = round_fp4(w / s_q)
        w_hat = q * s_d

This kernel does NOT change calibration. It only measures how much DSS could reduce the per-block reconstruction loss versus the coupled (s_q == s_d) sweep that NVFP4MSECalibrator already runs. For each NVFP4 block it sweeps every FP8 s_d candidate against a multiplicative s_q = beta * s_d grid and reports, per block:

  • coupled_loss — best loss over s_d at beta == 1 (reproduces today’s sweep),

  • dss_loss — best loss over the full (s_d, beta) grid,

  • best_beta — the beta at the DSS optimum.

Because beta == 1 is in the grid, dss_loss <= coupled_loss by construction; the diagnostic question is whether coupled_loss - dss_loss is ever materially positive.

default_dss_betas(device='cpu')

SOAR’s quant-scale grid: s_q = beta * s_d for beta in [0.50, 1.50] step 0.01.

Built as arange(50, 151) / 100 so the coupled reference beta == 1.0 is exactly representable (100 / 100), which nvfp4_dss_diag_sweep() requires.

nvfp4_dss_diag_sweep(x, global_amax, betas, block_size=16)

Measure DSS vs. coupled NVFP4 per-block reconstruction loss.

Parameters:

  • x (Tensor) – Weight tensor on CUDA. Total element count must be divisible by block_size; layout is treated as a flat [N_BLOCKS, BLOCK_SIZE] (matching the calibrator).

  • global_amax (Tensor) – Scalar FP32 global amax (= reduce_amax(per_block_amax)).

  • betas (Tensor) – 1-D FP32 quant-scale multipliers s_q = beta * s_d. Must contain exactly one entry equal to 1.0 (the coupled reference); its index drives coupled_loss.

  • block_size (int) – NVFP4 block size (typically 16).

Returns:

(coupled_loss, dss_loss, best_beta), each shape [N_BLOCKS] fp32 on x’s device. dss_loss <= coupled_loss elementwise by construction.

Return type:

tuple[Tensor, Tensor, Tensor]
