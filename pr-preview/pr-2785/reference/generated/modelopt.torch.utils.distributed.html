class DistributionPlan#

Bases: object

How a HuggingFace MoE model is distributed for PTQ, as decided by decide_distribution_plan.

  • ep_size – expert-parallel degree: the routed experts are sharded over ep_size ranks.

  • fsdp_size – dense-FSDP degree: 1 replicates the dense (non-expert) part on every rank; >1

    FSDP2-shards it alongside the expert-parallel experts.

Every rank calibrates on its own data, so data-parallelism spans the whole world, and each expert shard is replicated edp = world_size / ep_size times.

class ModelOptSession#

Bases: _SyncedHolder

The live distributed session of a PTQ run: this process’s identity, plus the model’s EP mesh.

One class covers both cases: distributed is False for a single process (WORLD_SIZE==1) and True for a real torch.distributed launch (WORLD_SIZE>1). Two parts, with different lifetimes:

  • process IDENTITY (distributed/rank/world_size/local_rank/device/is_main) – stable for the whole run, populated once by modelopt_session(). Reading ANY before initialization raises, so code cannot silently consume a stale/zero default before the process group is set up.

  • ep_mesh – the expert-parallel device mesh of the loaded model, set by load_and_prepare_ep (None until then, and for a model loaded without expert parallelism).

Facts annotated Synced, such as plan, hold the same value on every rank. The models of the run are held in models, a ModelRecord each, by role.

all_reduce(label, fn, combine)#

Return combine of every rank’s fn(), on every rank; keep nothing.

For a value no later stage reads back from the session; a fact that one does is a Synced attribute, set with its own all_reduce. combine takes the ranks’ values in rank order and returns the one every rank gets, e.g. min for a batch size each rank’s memory bounds, where one rank’s choice could run another out of memory. If fn raises on any rank, every rank raises, instead of waiting in the gather that rank never joins. Ranks reducing different labels at the same point fail. Collective; outside a distributed session fn runs alone.

broadcast_from(label, fn, rank=0)#

Return fn() run on rank only, on every rank; keep nothing.

For a value that depends on what each rank reads for itself – the environment, its GPU, files on its node – so that ranks computing it for themselves could disagree. If fn raises, every rank raises, instead of waiting in a broadcast rank never sends. Ranks broadcasting different labels at the same point fail. Collective: every rank calls it at the same point, with the same rank. Outside a distributed session fn runs alone. A fact a later stage reads back is a Synced attribute, set with its own broadcast_from.

class ModelRecord#

Bases: _SyncedHolder

One model of the run, held on its ModelOptSession under a role, "target" say.

model is this rank’s own instance, never communicated: each rank holds its own, or its shard of the weights. Every other fact is the same on every rank: the synced facts are kept so, as the session’s are, and the others are derived from values that already are. The loaders and the export also record these facts on the model itself, as _modelopt_<fact>, which is all a model loaded outside a session has.

class Synced#

Bases: Generic[_T]

A fact of the session every rank holds the same value of, declared by its type.

plan: Synced[DistributionPlan] on the session makes session.plan this handle. Read the value with session.plan.value: local, None until it is set. Set it with broadcast_from(), one rank computing it, or all_reduce(), every rank computing its own and the results combined; both are collective, so every rank calls them at the same point. Assigning session.plan raises, so nothing communicates behind an =. Declare one only for a fact a later stage reads back: a one-off value nothing reads back is ModelOptSession.broadcast_from() or ModelOptSession.all_reduce(), which keep nothing.

fsdp2_wrap(model, shard_root=True, mp_policy=None, cpu_offload=False)#

Auto-detect a HF causal-LM’s decoder layers and FSDP2 fully_shard each one.

By default (shard_root=True) the root module is wrapped too, so embed/lm_head/norm are sharded instead of replicated per rank; pass shard_root=False to leave the root replicated (only decoder layers sharded). Returns the detected decoder layers so callers can reuse the detection result.

Parameters whose dtype differs from the model’s dominant one are excluded from the wrap (see _off_dtype_params()), since FSDP2 rejects a shard group that mixes dtypes. They stay replicated and are moved onto the shards’ device, which fully_shard does not do for the params it ignores.

Parameters:

cpu_offload (bool)

modelopt_session(timeout=None, device=None)#

Populate the active session for the block, then tear down.

On a distributed launch (WORLD_SIZE>1) this initializes the process group (binding the local CUDA device) with timeout and records rank/world_size/local_rank/cuda:local_rank/is_main; it DESTROYS the group on exit even if the body raises. Single-process records the trivial single-rank topology – with device as the device (the caller’s default, e.g. the --device CLI value, since there is no local rank to derive one) – and enter/exit are no-ops around the body.

Every rank must run the same library versions: entering raises on every rank when one differs.

Yields the session (also reachable via get_active_mo_session()); it is reset on exit.

Parameters:

timeout (timedelta | None)
