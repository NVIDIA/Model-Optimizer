distributed_eval#

Optional, fault-tolerant distributed evaluation for Puzzletron.

This package is intentionally isolated from the existing local evaluator and rpc_eval scaffold. Import it explicitly when distributed evaluation is desired; importing modelopt.torch.puzzletron does not start services or change scoring behavior.
