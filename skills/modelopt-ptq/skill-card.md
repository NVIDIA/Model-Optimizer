## Description: <br>
Produces a quantized Hugging Face checkpoint from a pretrained model using NVIDIA Model Optimizer (ModelOpt) post-training quantization (PTQ), covering formats such as NVFP4, FP8, INT8, and INT4 AWQ for LLMs, MoE models, and VLMs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Owner
NVIDIA <br>

### License/Terms of Use: <br>
Apache 2.0 <br>
## Use Case: <br>
Developers and engineers use this skill to have an agent run ModelOpt post-training quantization on a pretrained model for a selected recipe or format, including environment setup, format selection, calibration on local, Docker, or SLURM targets, and mandatory post-export checkpoint validation. <br>
