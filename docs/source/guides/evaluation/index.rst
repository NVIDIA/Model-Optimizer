Evaluation
==========

* ModelOpt skills: for standardized evaluation and acceptance checks before
  releasing optimized models, follow the
  `ModelOpt evaluation skill <https://github.com/NVIDIA/Model-Optimizer/blob/main/skills/modelopt-evaluation/SKILL.md>`__
  and
  `ModelOpt results-comparison skill <https://github.com/NVIDIA/Model-Optimizer/blob/main/skills/modelopt-compare-results/SKILL.md>`__.

* `LLM evaluation examples <https://github.com/NVIDIA/Model-Optimizer/blob/main/examples/llm_eval/README.md>`__:
  benchmark frameworks, setup, and evaluation commands.

* :doc:`Evaluating Models Efficiently During Optimization Experiments <../../announcements/evaluating_models_efficiently_during_optimization_experiments/index>`:
  evaluate models quickly and reliably during optimization experiments, with worked examples
  of metrics, regression and reliability checks, and evaluation budgets.
